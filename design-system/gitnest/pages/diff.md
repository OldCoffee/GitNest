# Diff / Preview overrides

> Overrides `design-system/gitnest/MASTER.md` for file diff and preview tabs.

## Rules
- Preview chrome uses `jb-preview-header` with left accent bar (same language as tool windows)
- Path is primary; mode / kind / language / size are `jb-preview-meta` pills
- Unified / Split toggle uses `Tabs variant="segmented"` (`.jb-segmented`)
- Keep domain colors for add/delete word highlights
- Errors use `InlineAlert`, not raw red text blocks
