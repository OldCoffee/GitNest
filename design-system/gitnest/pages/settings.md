# Settings page overrides

> Overrides `design-system/gitnest/MASTER.md` for Settings.

## Rules
- Use `EditorTabShell` with page title in chrome header
- Group settings into `jb-page-section` panels (not ToolWindowHeader)
- Forms use `FormField` + `Input` / `Select` / `Checkbox`
- Sticky `jb-page-footer` holds Save + version meta
- Verification / save feedback via `InlineAlert`
- Keep density high; max content width ~42rem
